# Contents
- `hx/` — the CN client's `_hx` paintings (검열판), laid out like `data_for_toy/output_expressions/`:
  `hx/<skin_id>/painting.png` / `painting_n.png`, plus face patches only where they differ from the
  ones in data_for_toy. `hx/manifest.json` lists every entry.
